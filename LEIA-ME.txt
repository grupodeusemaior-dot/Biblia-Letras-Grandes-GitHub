COMO APLICAR NO GITHUB WEB:
1. Extraia este ZIP no computador.
2. Abra o repositório do aplicativo no GitHub.
3. Na raiz do repositório, clique em Add file > Upload files.
4. Envie os três arquivos para a raiz, substituindo os arquivos de mesmo nome.
5. Clique em Commit changes e confirme na branch main.
6. Aguarde o GitHub Pages atualizar.
7. No celular, feche o app completamente e abra novamente. Se continuar mostrando a versão antiga, abra o site no navegador e atualize a página; depois abra o app instalado novamente.
